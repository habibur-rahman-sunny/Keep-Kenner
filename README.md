# Keep-Keener

## Project Description
Keep-Keener is a simple and user-friendly web application that helps users manage their friends' activities and track communication history. The project focuses on a clean UI, smooth user experience, and efficient data management.

## Technologies Used
- Html
- Tailwind Css
- JavaScript
- React.js
- Next.js

## Key Features

### 1. Friends Management
- Display a list of friends with their details.
- View individual friend profiles.
- Easy navigation between pages.

### 2. Timeline Tracking
- Track communication history like calls, messages, and video calls.
- Filter timeline activities by type.
- View upcoming interaction dates.

### 3.Responsive & Modern UI
- Fully responsive design for mobile, tablet, and desktop.
- Clean interface with Tailwind CSS.
- Fast navigation using Next.js routing.
